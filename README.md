# GitHub OAuth Token Manager & Simulator
Created by Mamun (https://www.facebook.com/rtmamun11)

## How to Run / Deploy:
1. Local: Open `index.html` directly in any web browser.
2. Netlify: Drag and drop `index.html` at https://app.netlify.com/drop
3. GitHub Pages: Upload `index.html` to a GitHub repository and enable Pages in Settings.
